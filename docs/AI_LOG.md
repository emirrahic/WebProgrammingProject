# AI Log

## Milestone 1

### Tools and tasks
I used Claude (claude.ai) as a supporting tool during Milestone 1 to get design ideas, solve some Bootstrap issues, and fix image sizing problems in the frontend. I also used it to help create the static data in frontend/js/data.js, so I did not have to manually come up with all the sample book and library data myself. I used these suggestions to improve the appearance and functionality of the static frontend while keeping the project simple and focused on the requirements of Milestone 1.
I used it also for some javascript functions.
### Where the AI was wrong
I had some trouble getting the dashboard picture to the right size. It was too large for the layout, so I used Claude to help me adjust the image sizing to fit the page properly.
